# 📱 Islamic Flutter App

A beautiful and feature-rich **Islamic mobile app** built with Flutter — designed to help users read the Quran, reflect on Ahadeth, make tasbeeh, and more.  
This is a multi-tabbed application with practical navigation, offline file support, and interactive UI components — ideal for everyday spiritual engagement.

---

## ✨ Intro Screen

• A smooth, modern introduction screen with **5 swipeable tabs**  
• Each tab explains one of the app’s main features (Quran, Hadeth, Sebha, Radio, Time)  
• Designed to give first-time users a friendly, guided overview  
• Only shown on the first launch using local storage logic

---

## 🕌 Features Overview

### 📖 Quran Tab
• Displays all 114 Surahs in a vertically scrollable list  
• Reads Surah content from local files (1 file per Surah)  
• Tapping a Surah opens a new screen with its full content  
• Automatically stores recently opened Surahs and displays them in a horizontal scrollable list at the top  
• Includes a **search field** to find Surahs by Arabic or English names  
• Efficient and organized use of file handling in Flutter

---

### 📚 Ahadeth Tab
• A clean, scrollable list of Hadiths  
• Beautiful and minimal layout for easy reading  
• Content presented for inspiration and knowledge

---

### 🧿 Sebha Tab
• Functional digital Sebha (tasbeeh counter)  
• Visual Sebha rotates with every tap  
• Counter increases with each tap  
• Every 33 taps, the displayed **Zekr** automatically changes  
• Realistic experience inspired by traditional tasbeeh

---

### 📻 Radio Tab *(UI only)*
• Placeholder screen for future live Islamic radio streaming  
• Interface is ready — just waiting for API integration

---

### 🕓 Prayer Times Tab *(UI only)*
• Beautifully designed prayer times screen  
• Currently static — ready for dynamic API integration in the future

---

## 🛠 What I Learned

• Working with **local file reading** and structured data in Flutter  
• Creating responsive and interactive **ListViews** (vertical + horizontal)  
• Saving state and managing recent activity (most recently opened Surahs)  
• Building a custom **counter-based widget** (Sebha) with visual rotation  
• Designing a one-time **intro screen** using persistent storage  
• Planning UI/UX that balances practicality with elegance  
• Preparing for API integrations by structuring future tabs
